# gReader News 0.0.3

Android versionName 0.0.3 / versionCode 3. Package ID remains app.greaderapp.com.

## Reading and images
- Responsive article images now resolve each srcset candidate separately, including picture sources, lazy image candidates and video posters. (df7fcc3)
- Reading mode resolves images and links against the final redirected article URL. (85dc019)
- Opening an article respects Keep unread instead of automatically marking it read. (85dc019)
- Lazy-image URL attributes are checked before promotion into src/srcset, keeping them consistent with article sanitization. (2ab7dbe)

## Feed discovery and subscriptions
- Topic discovery has its own retry/error state. Topic searches and bundled-directory filters are separate, previous results clear when a new search starts, and stale responses no longer overwrite a newer topic or tab. (cc19442)
- Website feed discovery parses HTML metadata instead of regexes: entity-encoded URLs decode correctly, commented-out links and data-href lookalikes are ignored, rel/MIME tokens are exact, and HTTP(S) candidates are deduplicated. (d816d53)
- Relative feed links resolve against the final URL after a website redirects. (b923e39)
- Local storage failures are reported accurately rather than being mistaken for "No feed found" or triggering unrelated discovery requests. (b923e39)

## Build and test maintenance
- Workflows moved to self-hosted runners; Android SDK provisioning and SDK-license handling were revised. These workflow changes are included, but their presence does not prove the current Android pipeline is passing. (de1022f, cd42c9b, 013086e, 553fb63)
- Added regression coverage for responsive media, topic retry/stale responses, feed metadata, redirects/storage failures, Keep unread and lazy-media sanitization.
- List-preferences tests now inject a storage adapter instead of depending on Capacitor module mock order, removing the flake observed during the article-page gate. (85dc019)

## Release preparation
- Package and lockfile version: 0.0.3.
- Android versionName/versionCode: 0.0.3 / 3.
- iOS project metadata aligned to 0.0.3 / build 3; no iOS build is certified by this preparation.
- Existing on-device AI summaries, OPML support and local RSS features remain; Flutter migration is a separate specification, not part of this release.

## Verification and release cautions
- The code baseline before the version bump passed 221 Angular tests and 26 server/worker tests, lint and web build. Release-prep gates and signed artifact checks must also pass on the final version commit.
- Today's web fixes were manually deployed by the host and verified by served-bundle identity; behavior regression coverage includes local browser fixtures, not a complete real-Android acceptance run.
- No Google Play upload/rollout or tag/release creation is performed by this preparation. Check the current Play Console highest versionCode before uploading; source code 3 is not proof that Play has not already used it.
- Real-device AI battery/memory validation and unverified native widget behavior remain separate follow-up work.
